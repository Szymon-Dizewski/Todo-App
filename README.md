# Todo List

A simple React todo list app. Add tasks, mark them done and tap the trash button to remove completed items.

## Features

- Add tasks
- Mark tasks as done (with strike-through styling)
- Swipe-to-delete on mobile > !TODO
- Delete completed tasks via a fixed trash button

## Tech Stack

- React (hooks-based, no external state management library)
- Plain CSS

## Getting Started

```bash
npm install
npm run dev
```
